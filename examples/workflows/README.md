# Example Workflows

This directory contains public-safe ScholarFlow workflow examples.

## Available Examples

- [phase8-vlm-hallucination](./phase8-vlm-hallucination): a synthetic example showing Paper Table, Deep Paper Card, Gap Board, Idea Validation Report, and Experiment Plan artifact shapes.

## Data Policy

Examples must not include real private papers, private PDFs, local API responses, user research notes, application materials, logs, database files, or unpublished claims.

Synthetic examples are allowed when they are clearly marked as illustrative and are not presented as real citations.
