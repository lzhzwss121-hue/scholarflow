# ScholarFlow v0.1.0 Release Notes

Release date: 2026-06-29

ScholarFlow v0.1.0 is the first public preview of a Chinese-first AI research workflow agent. It is designed as a local-first workspace for turning a vague AI research direction into traceable artifacts: paper tables, Deep Paper Cards, gap boards, novelty checks, and experiment plans.

## Included

- React research workspace with project navigation, agent workspace, artifact preview, paper table, direction review, paper memory, paper reader, gap board, and experiment planner.
- FastAPI service with SQLite persistence for projects, papers, artifacts, sessions, tool events, paper cards, paper memories, direction memories, and agent runs.
- Node CLI for local workspace initialization and Web/API service management.
- Agent loop with plan mode, real registered research tools, timeline events, and artifact persistence.
- OpenRouter model provider using `minimax/minimax-m2.5` by default with local fallback when no API key is configured.
- arXiv and OpenAlex literature retrieval with query expansion, deduplication, ranking, and Paper Table artifact generation.
- Direction review workflow: 10 recent high-relevance papers per round, up to three rounds, with cumulative direction summaries and top-3 personal reading recommendations.
- Paper Memory Bank for retrieving 3-8 relevant paper memories before answering follow-up questions.
- BaselineMap generation for direction-level comparison background: classic baselines, recent strong baselines, alternative paradigms, benchmark risks, and open questions.
- Signal-aware ResearchSight generation for paper-level critique: why-good, why-not-good, better-angle, baseline comparison, next-step proposal, and critique-level evidence anchors.
- EvidencePack boundaries for critiques, including evidence snippets, confidence levels, and missing-evidence notes.
- 12-section Deep Paper Card workflow based on ScholarFlow's paper-reading protocol.
- PaperSignals extraction for task, method, dataset, metric, claim, limitation, contribution type, and missing-signal boundaries.
- Research decision bundle for true/engineering/pseudo gap classification, idea validation, and experiment planning.
- Experiment planning anchor selection that excludes survey/review papers and falls back to "missing reproducible anchor" when no method or benchmark paper has enough evidence.
- Real Agent Loop tools for literature search, direction review, paper memory query, research decision generation, artifact aggregation, and timeline finalization. Mock paper search remains available only as Demo Mode.
- Compact Agent Run artifacts that store tool summaries and artifact refs instead of nesting full intermediate outputs, plus failed-step persistence for tool errors.
- Web UI project selector and persisted artifact recall for direction review, paper memory, paper reader, gap board, and experiment planner views.
- Open-source release assets: CI, Issue templates, PR template, Security Policy, example workflow, and release notes.

## Not Included Yet

- DeepSeek as the primary model provider.
- Automatic PDF downloading or full-PDF batch parsing.
- PDF section parsing for high-recall method, dataset, metric, and experiment extraction.
- PDF-level evidence quotation and citation-graph grounding for critiques.
- Embedding/vector retrieval for Paper Memory Bank; the current memory retrieval is structured keyword ranking.
- Citation-graph baseline discovery and Best Paper / Meta Review RAG for research-aesthetic calibration.
- Background job queue, step cancellation, retry policy, and streaming tool progress for long Agent runs.
- Training, benchmark execution, or automatic reproduction runs.
- Full paper writing.
- Cloud service, paid product features, or multi-user lab collaboration.

## Verification

The v0.1.0 release should pass:

```bash
npm run check
npm run build
python3 -m compileall services/api/src/scholarflow_api
```

## Privacy Notes

The repository intentionally excludes local PDFs, SQLite databases, logs, API keys, vector stores, user artifacts, and private research data through `.gitignore`. Example workflow files are synthetic and are meant to show artifact shape, not to recommend real citations.
